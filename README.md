# Jewelix AI Studio

UI prototype for the Jewelix AI Studio plugin. All AI results are simulated in the browser; there is no backend yet.

- **Enhance**: product photo on a white background, with yellow / rose / white gold previews
- **Show on Model**: places the piece with a model photo
- **Blend**: combines two designs into a new one
- **Inventory Match**: searches stock from a client's reference photo (shows a "connect inventory" state until the ERP is linked)

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.

`visualizer-v1.html` is the earlier single-tool version.
